MSc Practicum Project, 2025-2026
MSc Computing (Data Analytics)

## Authors
Anonymized for review

## Research Questions
- **RQ1:** How do code-trained LLMs (CodeBERT, GraphCodeBERT) compare with traditional ML baselines (Random Forest) for vulnerability detection on the Juliet Test Suite?
- **RQ2:** Does a hybrid CodeBERT+GraphCodeBERT model improve recall and reduce false positives compared to non-hybrid models?
- **RQ3:** How accurate, clear, and useful are model-generated vulnerability explanations under expert review?
